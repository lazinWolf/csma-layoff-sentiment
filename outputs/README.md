# outputs/: what each folder is

Everything here is generated by a script and can be rebuilt; nothing here is edited by hand except the check sheets. Status:
- **core**: pipeline outputs the rest depends on;
- **current**: used in the findings;
- **exploration**: background, already summarised in the findings;
- **archive**: superseded.

**Read first:** [`04_analysis/FINDINGS_BY_HYPOTHESIS.md`](04_analysis/FINDINGS_BY_HYPOTHESIS.md).

| Folder | Status | Made by | What it is |
|---|---|---|---|
| `01_profile/` | core | `scripts/profile_data.py` | Raw-file audit: months, communities, schema |
| `02_preprocessing/` | core | `scripts/preprocess_data.py` | Build summary and audit of the SQLite database |
| `03_tables/` | core | `scripts/export_tables.py`, `screen_disruption.py` | Posts, comments, threads, reply edges, screen candidates (586 MB) |
| `04_analysis/` | core + **current** | `scripts/summarize_data.py`, `plot_eda.py` | Midterm descriptive stats and 5 figures. Also holds **FINDINGS_BY_HYPOTHESIS.md** |
| `05_sample/` | core | `scripts/sample_data.py` | 200-record reading sample and context packet |
| `07_annotations/` | core | `scripts/summarize_annotations.py` | Label counts for the reading sample (still unreviewed) |
| `08_midterm/` | core | (midterm comparison) | H1 shared-window comparison and lexical stance baseline |
| `09_leads/` | exploration | `scripts/explore_leads.py` | Markers, precision samples, provisional manual codes (`manual/`), H-1B spike |
| `10_language/` | exploration | `scripts/explore_language.py` | Distinctive vocabulary per community and over time. Notes: `LANGUAGE_NOTES.md` |
| `11_dynamics/` | exploration | `scripts/explore_dynamics.py` | Language change, who adopts new words, voting style, linked sources. Notes: `DYNAMICS_NOTES.md` |
| `12_replies/` | **current (H3)** | `scripts/explore_replies.py` | Kind of comment → kind of reply table, examples, Gephi type network, **check sheet**. Notes: `REPLY_NOTES.md` |
| `13_interpretation/` | **current** | `scripts/check_interpretations.py` | Step-4 checks used in the findings (H1 thread spread, AI-excuse denominator) |
| `14_directions/` | **current** | `scripts/explore_directions.py` | Four directions: same author in two communities, sympathy and return, H-1B shock, core vs periphery. Notes: `DIRECTIONS_NOTES.md` |
| `archive/` | archive | n/a | The Nov 15 plan (done) and the first leads notes (summarised in the findings) |

There is no `06_` folder; the number was skipped in the original pipeline.

`09_leads/` to `14_directions/` are read-only analyses. Each script only reads `data/processed/reddit.sqlite` and writes to its own folder. Run them with `.venv-eda/bin/python scripts/<name>.py`.
