# outputs/: what each folder is

Everything here is generated by a script and can be rebuilt; nothing here is edited by hand except the check sheets. Status:
- **core**: pipeline outputs the rest depends on;
- **current**: used in the findings;
- **exploration**: background, already summarised in the findings;
- **archive**: superseded.

**Read first:** [`docs/PROJECT_REFERENCE_2.md`](../docs/PROJECT_REFERENCE_2.md). It sets out the project as layers, from 0 (collection) to 7 (concepts). The Layer column below uses those numbers.

| Folder | Layer | Status | Made by | What it is |
|---|---|---|---|---|
| `01_profile/` | 0 | core | `scripts/profile_data.py` | Raw-file audit: months, communities, schema |
| `02_preprocessing/` | 1 | core | `scripts/preprocess_data.py` | Build summary and audit of the SQLite database |
| `03_tables/` | 1 | core | `scripts/export_tables.py`, `screen_disruption.py` | Posts, comments, threads, reply edges, screen candidates (586 MB) |
| `04_analysis/` | 2 | core + **current** | `scripts/summarize_data.py`, `plot_eda.py` | Midterm descriptive stats and 5 figures |
| `05_sample/` | 3 | core | `scripts/sample_data.py` | 200-record reading sample and context packet |
| `07_annotations/` | 3 | core | `scripts/summarize_annotations.py` | Label counts for the reading sample (still unreviewed) |
| `08_midterm/` | 4 | core | (midterm comparison) | H1 shared-window comparison and lexical stance baseline |
| `09_leads/` | 3 | exploration | `scripts/explore_leads.py` | Markers, precision samples, provisional manual codes (`manual/`), H-1B spike |
| `10_language/` | 4 | exploration | `scripts/explore_language.py` | Distinctive vocabulary per community and over time. Notes: `LANGUAGE_NOTES.md` |
| `11_dynamics/` | 4 | exploration | `scripts/explore_dynamics.py` | Language change, who adopts new words, voting style, linked sources. Notes: `DYNAMICS_NOTES.md` |
| `12_replies/` | 5 | **current (H3)** | `scripts/explore_replies.py` | Kind of comment → kind of reply table, examples, Gephi type network, **check sheet**. Notes: `REPLY_NOTES.md` |
| `13_interpretation/` | 4 | **current** | `scripts/check_interpretations.py` | Step-4 checks used in the findings (H1 thread spread, AI-excuse denominator) |
| `14_directions/` | 4 | **current** | `scripts/explore_directions.py` | Four directions: same author in two communities, sympathy and return, H-1B shock, core vs periphery. Notes: `DIRECTIONS_NOTES.md` |
| `15_network/` | 6 | **current** | `scripts/explore_network.py` | R4: author types in the cscq reply network (centrality, mixing, nulls, communities, k-means, rivals, GEXF). Notes: `NETWORK_NOTES.md` |
| `16_tableau/` | all | **current** | `scripts/export_tableau.py` | Tidy CSVs for Tableau, one set per result (R1–R5), at the day, thread, comment, reply-pair, author, type-flow and network-layout level. No text or ids. Guide: `TABLEAU_GUIDE.md` |
| `archive/` | — | archive | n/a | The Nov 15 plan (done), the first leads notes, `PROJECT_REFERENCE_2_by_result.md` (the earlier by-result version of `docs/PROJECT_REFERENCE_2.md`), and `FINDINGS_BY_HYPOTHESIS.md` (the Nov 19 results by H1–H3, now covered by layers 4–7) |

There is no `06_` folder; the number was skipped in the original pipeline.

`09_leads/` to `15_network/` are read-only analyses. Each script only reads `data/processed/reddit.sqlite` and writes to its own folder. Run them with `.venv-eda/bin/python scripts/<name>.py`.
